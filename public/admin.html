Install ZONIX Admin on Phone

Add ZONIX Web Admin to your smartphone home screen as a standalone mobile app.

📱 iOS (iPhone / iPad):
  1. Open https://thezonix.com/admin.html in Safari.
  2. Tap the Share button (bottom toolbar).
  3. Scroll down and tap Add to Home Screen.
🤖 Android (Chrome):
  1. Open https://thezonix.com/admin.html in Chrome.
  2. Tap the 3 dots menu (top right).
  3. Tap Install app or Add to Home Screen.
